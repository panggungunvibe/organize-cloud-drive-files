# 使用原网站的真实素材界面

`assets/web/` 复用已完成的相册整理网站。保留原网站布局、确认步骤、180 份代表封面形成的密集素材球、弧线飞入两侧最末级目录和缩略图堆叠；只将原项目的固定相册、城市、媒体数量及任务状态改为动态数据。

## 填入素材

1. 按 `plan-schema.md` 写逐文件方案，在工作区 `public/thumbs/` 放实际图片封面或视频帧。
2. 用 `import-plan.mjs` 导入。导入会记录封面内容摘要，预览按身份与封面内容去重；源文件仍全部保留在方案内。
3. `serve.mjs` 为 `/api/view` 提供展示数据。界面从同一方案生成统计、逻辑层级、目录卡片、叶子文件夹和飞行目标。

无视频时自动把照片目录分布在两侧，不制造视频。没有封面的条目使用清楚的原文件名卡片；不得用图标插画当作该条目的真实照片。文件名相同但身份不同的素材按 `id` 与目标路径映射，不按名称猜目标。

封面球使用不重复的代表图，目录数字显示完整方案数量。预览飞入的都是该目标目录的真实条目；归档后堆叠更多同目录封面，表现素材逐渐归位的密度。

## 本地核对

默认 URL 从第一步开始；`?preview=sorting&paused=1` 只打开素材球静态预览，点击播放后继续完整动画，不跳过最终授权。`?preview=sorting` 自动播放动画，仍不能自动提交网盘操作。

至少用实际素材核对：封面是否可读、是否铺满星球、左右叶子目录是否正确、每张封面是否落入自己的目标、无视频时布局是否正常。动画结束后才出现最终确认；播放、重播、暂停预览都不操作网盘。

公开仓库展示与本地真实素材预览分开。不要将私人相册、任务清单、结果截图随安装包公开，也不要另生成虚构数字的占位相册充当使用效果。
